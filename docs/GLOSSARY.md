# Glossary — Turkish → English

The single source of truth for terminology in KAREN's code, comments, docs and UI.
Every translation pass uses these terms verbatim. Adding a term is fine; renaming an
existing one requires updating every occurrence in the same commit.

## Style

- Sentence case for headings and buttons; no trailing period on labels.
- Second person, active voice: "Search memory", not "Memory search is performed".
- Numbers: `1.234` grouping and `,` decimal for `en`; the `tr` dictionary uses `1.234` / `,` as Turkish convention requires (`tr-TR`).
- Never translate: product names (KAREN), model names, file paths, tool names, env vars.
